# International Student Guide Bot

This is a Telegram bot designed to help international students, with an initial focus on Iranian students in Perugia, Italy.

## Features

*   Multi-language support (Farsi, English, Italian)
*   User profile creation and editing
*   ISEE calculator
*   Information on scholarships, housing, and other aspects of student life
*   And much more!

## Getting Started

1.  Clone this repository.
2.  Install the required dependencies: `pip install -r requirements.txt`
3.  Create a `.env` file based on the `.env.example` and fill in the required environment variables.
4.  Run the bot: `python main.py`
